# Lemon Milk Pro

`Lemon Milk Pro` — платная retail-версия шрифта Marsnev с отдельной лицензией. Файл шрифта намеренно не включён в репозиторий.

После приобретения подходящей **webfont-лицензии** поместите разрешённый WOFF2-файл сюда под именем:

`lemon-milk-pro-variable.woff2`

CSS уже содержит `@font-face`, `font-display: swap` и безопасный fallback. До добавления файла браузер использует `Avenir Next`, `Montserrat` или системный sans-serif. Проверьте, разрешает ли ваша конкретная лицензия хранение webfont-файла в публичном GitHub-репозитории; при запрете используйте приватный процесс доставки ассета.

Официальная информация: https://marsnev.com/licensing/
