# Как добавить проект

Создайте в этой папке два файла с одним и тем же номером:

- `nazv15.txt` — название проекта (обязательный файл);
- `link15.txt` — полная ссылка, начинающаяся с `https://` (обязательный файл).

Если нужно описание, добавьте `opis15.txt`. Этот файл необязателен: без него проект всё равно появится на сайте.

Номер может быть любым неотрицательным целым числом без ведущих нулей: `1`, `2`, `10`, `999`. Чем больше номер, тем выше проект будет в списке.

После сохранения выполните:

```bash
git add .
git commit -m "Add project 15"
git push
```

GitHub Actions автоматически прочитает файлы, пересоберёт сайт и опубликует обновление. Если название или ссылка отсутствуют, сборка покажет предупреждение, пропустит только эту запись и продолжит работу.
