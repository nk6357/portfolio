# Официальный логотип НИУ ВШЭ

Логотип намеренно не скопирован в репозиторий: доступность файла для скачивания сама по себе не подтверждает право на его повторное распространение в публичном репозитории.

1. Получите разрешённую SVG-версию на официальной странице фирменного стиля НИУ ВШЭ: https://www.hse.ru/info/brandbook/
2. Убедитесь, что ваш способ использования соответствует правилам бренда.
3. Замените технический placeholder `hse-logo.svg` разрешённым официальным SVG под тем же именем.
4. Не меняйте пропорции и внутреннюю композицию логотипа.

Компонент на главной уже подключён: после замены файла он покажет официальный логотип без изменения кода.
